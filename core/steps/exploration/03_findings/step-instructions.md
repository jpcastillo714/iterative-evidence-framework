# Instrucciones: Paso 03 - Findings (Exploration)

| Campo | Valor |
|-------|-------|
| **Inputs** | Artefactos de análisis |
| **Output** | `findings.md` |
| **Human Gate** | NO |
| **Aplica a** | exploration |

## Propósito
Sintetizar lo descubierto en el análisis en un formato digerible para la toma de decisiones.

## Protocolo
1. Utiliza los artefactos creados en el paso 02.
2. Utiliza la plantilla de `findings.md` localizada en este directorio.
3. Plasma cada hallazgo indicando evidencia de respaldo, implicaciones para el proyecto y el nivel de confianza que se tiene (alta/media/baja).
4. Provee recomendaciones concretas para los siguientes incrementos.

## Criterios de Calidad
- Cada recomendación debe tener un tipo sugerido (build o exploration) y una prioridad.
- Referencia a los contratos de datos (data-contract.yml) si se crearon en el paso opcional 02b.
- Anota cualquier pregunta abierta o información que este incremento de exploración NO pudo responder y requerirá trabajo adicional.
